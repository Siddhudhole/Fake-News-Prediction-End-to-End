# Fake News Prediction (End-to-End)

This project is a complete pipeline for **Fake News Detection** using machine learning techniques. It demonstrates the entire workflow, from **data preprocessing** and **model development** to **evaluation** and **deployment**.

## 🚀 Key Features
- 📊 **Exploratory Data Analysis (EDA):** Understanding patterns and feature distributions in the dataset.  
- 🧹 **Text Preprocessing:** Cleaning, tokenization, stop-word removal, and feature extraction.  
- 🤖 **Model Training:** Applied ML algorithms for fake-news classification with performance evaluation (accuracy, precision, recall, F1-score).  
- 📈 **Version Control:** Dataset and models managed using **DVC** for reproducibility.  
- 🌐 **Deployment:** An interactive app (`app.py`) that predicts whether a given news article is real or fake.  
- ⚙️ **Reproducibility:** `requirements.txt` ensures environment consistency.

## 🛠 Tech Stack
- Python, Scikit-learn, Pandas, NumPy  
- NLP preprocessing tools (NLTK / similar)  
- DVC for data & model versioning  
- Streamlit/Flask (for deployment)  

This project showcases how to build a robust **end-to-end machine learning solution** for detecting fake news in real-world scenarios.
